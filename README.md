# Under the Lights

![Under the Lights logo](assets/logo.png)

**Under the Lights** is a season-long prediction game built around Soccerverse.

Each week, one meaningful match from anywhere in the Soccerverse world is placed under the spotlight. Players predict the result, exact score, goalscorers, assists, and key match events to earn points, unlock achievement badges, and compete across the season.
